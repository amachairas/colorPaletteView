The project is made for demo and educational purposes. 
That means that the code is not optimized or ready to use in a commercial product.

I use shaders and P5js. The idea is simple: Imagine seeing your city if it were painted using an artwork's color palette. There is one step before the video filter starts. You have to choose an artwork. The application will extract the color palette. 

It is easy to add more paintings, photos, or images. In the "images" folder, add the new paintings (in jpg format). Rename the image using the following number of the last upload e.g. "9.jpg" Then, in paletteView.js at line 262, change the "let cci = 8" to "let cci  = 9"

Enjoy!
